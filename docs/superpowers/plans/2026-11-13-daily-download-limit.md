# 每 IP 每日下载上限实施计划

目标：后台统一设置每个 IP 每天下载次数，不支持指定 IP 配置。
设计：D1 单例设置与按北京时间日期/IP 聚合计数；默认 NULL 不限，0 禁止，正整数限额。所有原图代理共用原子计数，预览不计数；上游失败不计，传输开始后取消仍计数。仅信任 Cloudflare IP 头。

实现裁定：保留当前工作区已有文档修改，不提交或部署；本地直接验证迁移，不操作远端数据库。原生下载前查询额度提供提示，实际下载仍原子核验。计数保留近 7 天，下载时小概率清理历史记录。
