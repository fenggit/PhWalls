# 小程序公开 API 实施计划

**Goal:** 为 PhWallsMini 提供在线品牌、集合和壁纸查询，生产数据以 D1 已发布记录为准。
**Architecture:** 参数/查询/DTO 模块、D1 数据访问模块、统一 HTTP 响应和四个 Edge GET 路由。仅修改 PhWalls 的 dev 分支。
**Tech Stack:** Next.js 15 Edge Runtime、TypeScript strict、Cloudflare D1；沿用 Node 内置验证方式，不增加测试框架。

## 契约与约束

- 根路径 /api/public/mini/v1，端点为 brands、collections、collections/[id]、wallpapers/[id]。
- kind=phone|live|desktop；brand 为归一化 slug；q 为品牌/机型关键词；lang=en|zh|ja|vi|zh-hant，默认 zh。
- page 默认 1，pageSize 默认 24、最高 60；错误参数 400，未发布/不存在详情 404，无 D1 绑定 503。
- 集合 ID 为 deviceId:static|dynamic；单张 ID 为 deviceId:static|dynamic:wallpaperId，客户端视为不透明标识。
- 设备与素材均 published 且 deletion_state=none 才可返回。静态/动态翻译独立，不返回 R2 直链或签名。
- 返回绝对预览、视频及服务端代理下载链接；成功/失败元数据均 no-store，后台发布状态立即影响查询。
- 保留现有网站路由、JSON 回退、媒体代理和中间件行为；不执行部署、不修改小程序仓库。
