# 壁纸英文标签与多语言 JSON 词表

`w_wallpapers.tags` 保存小写英文字符串数组，例如 `["abstract","gradient","fluid art"]`。英文名称既是可直接展示的英文，也是多语言 JSON 词表的匹配键；保留正常的英文空格和标点，不另造下划线标识。

现有 94 种标签覆盖 11,586 张壁纸，描述风格、画面内容及相关特征。小程序接口直接返回数据库中的英文 `tags`，不增加 `tagKeys`，也不根据 `lang` 转换标签。`lang` 对其他已有多语言字段的作用保持原有约定。

## JSON 格式

词表位于 `src/data/language/{en,zh,ja,vi,zh-hant}/wallpaper-tags.json`。五个文件使用完全相同的小写英文键；英文文件的值与键一致，其他文件的值为对应语言文案。

英文：

```json
{
  "abstract": "abstract",
  "gradient": "gradient",
  "fluid art": "fluid art"
}
```

简体中文：

```json
{
  "abstract": "抽象",
  "gradient": "渐变",
  "fluid art": "流体"
}
```

接口标签示例：

```json
{ "tags": ["abstract", "gradient", "fluid art"] }
```

需要本地化展示的使用方直接用英文标签匹配相应 JSON；英文展示直接使用原标签。现有服务端读取和返回逻辑保持不变。

网页详情现在传递完整 `tags[]`：卡片默认展示前 3 项，`+N` 打开预览查看完整标签。仅映射到十个英文主题白名单的标签提供链接，其他标签为普通文本；不按标签组合、设备或分辨率生成额外索引页。保留旧 `tag` 作为兼容单值字段，公开小程序仍直接返回英文数组。主题筛选不把明暗配对字段当作暗黑风格，具体规则与精选维护见[主题试点说明](wallpaper-discovery-seo.md)。

## 维护约定

- 英文标签一律小写，保持与英文 JSON 的键和值完全一致；新增标签时同步补齐五种语言和本文中的中文说明。
- 标签为数组，可同时包含风格、内容和相关特征；不同于 `w_devices.theme` 的单个主要视觉风格，也不同于 `w_wallpapers.theme` 的明暗配对标记。
- 后续后台或导入写入时，直接使用下表中的小写英文名称，不写中文标签或额外标识。
- 数据库的 JSON 数组、长度及原有写入校验保持现有实现，本次不新增在线转换、接口字段或数据库结构。

## 存量转换

`node scripts/backfill-wallpaper-tags.mjs --snapshot <最新D1导出.sql> --out <输出前缀>` 根据五语言词表生成转换 SQL、回滚 SQL、逐条修改清单与核验报告。脚本将已有翻译名称匹配为小写英文；未识别的标签会中止生成，避免猜测或丢失标签。

转换只修改标签与修改时间，校验原标签、素材键和修改时间以保护并发编辑。生成时验证五语言完整性、其他壁纸字段不变、重复执行幂等和精确回滚。现有 API 本来就直接返回库中的标签，转换后即可返回小写英文；本次数据转换无需部署新的接口代码。
